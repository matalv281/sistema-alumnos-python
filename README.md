# 📚 Sistema de Gestión de Alumnos

Proyecto desarrollado en Python que permite gestionar alumnos y sus notas mediante un menú interactivo en consola.

## 🚀 Funcionalidades

* Agregar alumnos
* Mostrar alumnos
* Buscar alumno
* Calcular promedio
* Mostrar mejor alumno
* Eliminar alumno

## 🧠 Tecnologías utilizadas

* Python (nivel inicial)
* Estructuras: listas y diccionarios
* Funciones
* Manejo de excepciones

## ▶️ Cómo ejecutar

```bash
python sistema_gestion_alumnos.py
```
